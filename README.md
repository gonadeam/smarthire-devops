# SmartHire – AI Powered Hiring Platform

SmartHire is a recruitment and hiring platform designed to simplify the hiring process for companies and job seekers.

## Features

- User Authentication
- Job Listings Management
- Candidate Application System
- Recruiter Dashboard
- Responsive UI
- Dockerized Deployment
- AWS EC2 Hosting

---

## Tech Stack

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Python
- Django

### DevOps & Deployment
- Docker
- AWS EC2
- GitHub

---

## Installation

### Clone Repository

```bash
git clone https://github.com/gonadeam/smarthire-devops.git
cd smarthire-devops
```

### Run with Docker

```bash
docker build -t smarthire .
docker run -d -p 80:8000 smarthire
```
